1. Rangkuman Materi
   -
      Prompt Engineering, adalah teknik menghasilkan prompt (instruksi) kepada Ai dengan cara yang lebih efektif
   dan terstruktur untuk dipahami oleh sistem mereka. Salah satu penyebab output yang dihasilkan tidak sesuai
   disebabkan input/masukan yang diberikan kurang memiliki konteks sehingga model justru berimajinasi dalam
   menerjemahkan konsep abstrak pengguna.

   Maka teknik yang tepat adalah menggunakan struktur RTCF, apa itu RTCF?
   - Role, memberikan peran, pekerjaan dan tujuan yang jelas untuk dipahami model sebagai pekerjaannya.
   - Task, paparkan secara singkat namun efektif, apa saja beban pekerjaan yang perlu dikerjakan oleh
           model Ai.
   - Context, berikan konteks yang jelas pada model mengenai pekerjaan yang perlu dikerjakan, dapat berupa
              persyaratan yang perlu dipenuhi, standar pengerjaan hingga pondasi yang dibutuhkan.
   - Format, kemudian tentukan output yang diperlukan.
  
     Lalu langkah terakhir adalah memverifikasi data dari output yang dihasilkan Ai, melakukan trial and error
     dan tidak menerima mentah-mentah data yang diberikan.

        Git adalah perangkat lunak version control system - yang diinstal pada komputer lokal, ia berperan untuk
     melacak setiap perubahan pada kode ataupun file yang tersimpan di komputer lokal. Sederhananya, git merupakan sistem yang
     melakukan pemeriksaan apakah ada perubahan yang terjadi pada kode maupun file yang tersimpan di komputer lokal secara mandiri.
     Sedangkan GitHub adalah server berbasis cloud yang berperan sebagai pusat untuk menyimpan dan mengatur file/repository Git secara
     online dan terstruktur serta mendukung kolaborasi.

        Kemudian ada working directory/tree yang merupakan salinan dari suatu proyek yang sedang dikerjakan. File-file yang terdapat
     di dalamnya diambil dari database yang tersimpan pada direktori Git yang kemudian akan ditempatkan pada komputer supaya mudah
     untuk digunakan dan dilakukan modifikasi.

        Setelah itu terdapat Git directory yang merupakan tempat Git menyimpan metadata dan object database dari sebuah proyek. Bagian
     ini merupakan komponen terpenting dalam Git karena berisi seluruh informasi yang dibutuhkan Git untuk mengelola proyek.

        Terakhir terdapat Staging area yang berupa file dan umumnya berada di dalam direktori Git serta berfungsi untuk menyimpan informasi
     mengenai perubahan apa saja yang akan dimasukkan ke dalam commit berikutnya. Dalam istilah teknis Git, staging area disebut sebagai index.

     Kemudian sekali, setelah pemaparan materi terdapat workshop dengan tujuan percobaan untuk membuat game atau website sederhana menggunakan
     bantuan Ai Assistance/Agent yang terkoneksi dengan GitHub.
